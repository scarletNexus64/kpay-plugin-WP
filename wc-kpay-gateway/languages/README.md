# Traductions

L'interface du plugin est en français. Pour la traduire :

1. Générez un catalogue depuis les sources (WP-CLI) :
   `wp i18n make-pot . languages/wc-kpay-gateway.pot`
2. Traduisez le `.pot` (Poedit, GlotPress…) vers `wc-kpay-gateway-<locale>.po`.
3. Compilez en `.mo` et déposez les deux fichiers ici.

Exemple pour l'anglais : `wc-kpay-gateway-en_US.po` / `.mo`.

Le domaine de texte est `wc-kpay-gateway`.
